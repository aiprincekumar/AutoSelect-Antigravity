## 📝 Description

Implemented the complete **Grill Me Keyboard Automation Suite** inside `Keyboard Automation/` providing a hybrid focus and automated keystroke selection workflow for Antigravity, IDE, and terminal chat interfaces.

### Architecture Highlights:
1. **Hybrid Approach:**
   - Visual/countdown focus preparation: Allows user to click on or switch to target chat window within a configurable countdown window (default: 5 seconds).
   - Real-time active foreground window title detection via Windows Win32 API (`GetForegroundWindow` / `GetWindowTextW`).
2. **Deterministic Keyboard Sequence:**
   - `Ctrl + L`: Focuses chat prompt input box.
   - `Shift + Tab`: Shifts keyboard focus back to option buttons.
   - `1` (or custom option): Selects Option 1 (Recommended answer).
   - `Enter`: Submits and confirms selection.
3. **Zero-Dependency Native Win32 ctypes Engine:**
   - Employs native `SendInput` with fallback to `keybd_event`.
   - Runs out-of-the-box on standard Python 3.8+ on Windows with 0 external pip dependencies.
   - Includes seamless interop/fallback for `pyautogui` if installed or requested.
4. **Resilient Shell Launchers:**
   - `run_grill_me.bat`: 1-click batch launcher for Windows desktop/explorer double-click with delayed expansion and error pausing.
   - `run_grill_me.ps1`: Parameter-driven PowerShell runner with automatic virtual environment discovery.
   - `tests/test_grill_me.py`: Automated unit test suite verifying virtual key mapping, dry-run execution, and window title detection.
