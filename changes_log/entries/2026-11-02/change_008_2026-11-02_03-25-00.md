## 📝 Description

Implemented an intelligent window auto-targeting, focus, restoration, and full-screen maximization subsystem into the **Grill Me Keyboard Automation Suite** (`Keyboard Automation/grill_me_automation.py`), with updated batch and PowerShell runners, documentation, and unit tests.

### Architecture Highlights:
1. **Intelligent Window Enumeration & Detection (Win32 ctypes):**
   - Active scanning of top-level windows via `EnumWindows` and `GetWindowTextW`.
   - Matching against target keyword (default: `"Antigravity"`).
   - Scoring heuristic prioritizes exact match and de-prioritizes runner console/terminal windows.
   - Built-in exclusion of the runner's own console window (`kernel32.GetConsoleWindow`).
2. **Auto-Restore (Un-minimize):**
   - Detects if the target window is minimized via `user32.IsIconic(hwnd)`.
   - Restores window to normal active state via `user32.ShowWindow(hwnd, SW_RESTORE)` prior to maximizing.
3. **Auto-Maximize (Full Screen):**
   - Detects if the target window is not maximized via `user32.IsZoomed(hwnd)`.
   - By default (`auto_maximize=True`), expands the target window edge-to-edge via `user32.ShowWindow(hwnd, SW_MAXIMIZE)`.
4. **Foreground Lock Bypass & Focus:**
   - Robust Windows OS foreground lock release using thread input attachment (`AttachThreadInput`) and synthetic `Alt` key event (`VK_MENU = 0x12`).
   - Ensures window foreground activation via `BringWindowToTop`, `SetForegroundWindow`, and `SetFocus`.
5. **Geometry Verification & Settling Delay:**
   - Inspects window dimensions and boundary coordinates via `user32.GetWindowRect`.
   - Configurable settle delay (`--settle-delay 0.5s`, default 500ms) ensuring UI rendering and animation stabilization before keystroke injection.
   - Verified post-conditions: foreground state, maximized status, and bounds.
6. **Graceful Fallback:**
   - If target window is not found, issues clear warning and continues with active foreground window or countdown.
7. **CLI Customization:**
   - Default: `--auto-focus` (True), `--auto-maximize` (True), `--target-window "Antigravity"`, `--settle-delay 0.5`.
   - Opt-out flags: `--no-auto-focus`, `--no-auto-maximize`.
8. **Shell Launchers & Documentation:**
   - Updated `run_grill_me.bat` with auto-targeting and maximize documentation.
   - Updated `run_grill_me.ps1` with new parameters (`-TargetWindow`, `-NoAutoFocus`, `-NoAutoMaximize`, `-SettleDelay`, `-NoCountdown`).
   - Updated `Keyboard Automation/README.md` with complete architecture diagram, quick start examples, and CLI reference.
