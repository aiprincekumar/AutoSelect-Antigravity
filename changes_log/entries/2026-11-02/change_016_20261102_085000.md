## 📋 User Inquiry & Objective

The user requested two dedicated subfolders in this project workspace:
1. **Subfolder 1: Question Detection (`Question Detection/`):**
   - Purpose: Detect how many questions are currently asked in a single interactive prompt / quiz in Antigravity (e.g., 1, 2, 3, 4, 5 questions).
   - Critical Requirement: Count the NUMBER OF QUESTIONS, NOT the number of options.
   - Capabilities: Screen / active window detection + heuristic / visual or simulation mode, `--simulate N`, `--detect`, CLI flags with fallback, and writes `question_count.json`.
   - Deliverables: `detect_questions.py`, `run_detection.bat`, `README.md`.
2. **Subfolder 2: Quiz Keyboard Automation (`Quiz Automation/`):**
   - Purpose: Execute the multi-question shortcut loop based on the detected question count.
   - Requirements:
     - Takes question count from CLI (`--questions N` or reads automatically from `question_count.json`).
     - Targets Antigravity 2.0 (using robust restoration, maximization, and focus bypass).
     - Keystroke Loop:
       For q = 1 to N:
         - `Ctrl + L` (focus input)
         - `Shift + Tab` (reverse tab to option)
         - `1` (select Option 1)
         - If q == N (last question): Press `Enter` (Submit).
         - If q < N: Do NOT press Enter! Settle delay and continue to next question.
     - Supports `--dry-run` and configurable delays.
   - Deliverables: `quiz_automation.py`, `run_quiz.bat`, `run_detection_and_quiz.bat`, `README.md`.
