## 🏛️ Overview

This directory houses the **Simple and Classic Dashboard** for the `AutoSelect-Commander` automation suite. It is preserved in its original, pristine state as a rock-solid, production-certified baseline.

### 📁 Files in this Directory
- `dashboard.html`: The complete, self-contained original dashboard HTML with zero external dependencies.
- `automation_history.json`: Historical execution telemetry and question records.
- `run_classic_dashboard.bat`: 1-click batch launcher to open the Simple and Classic Dashboard in your browser.
