## 📝 Description

Relocated and integrated the modular step-by-step GUI mouse automation suite into `AutoSelect-Commander\scripts\gui_automation\`. This suite solves single-loop automation hanging by isolating each mouse action into its own independent script with configurable UI settling delays, smooth Bezier cursor motion (`easeOutQuad`), interactive screen coordinate calibration, and an automated verification runner.

## 📂 Files Included

- `scripts/gui_automation/config.json`: Step coordinates, timings, and easing configuration.
- `scripts/gui_automation/common_utils.py`: Shared smooth mouse travel, hover, and click engine.
- `scripts/gui_automation/step1_open_and_click_chat.py`: Step 1 chat focus action.
- `scripts/gui_automation/step2_select_recommended_option.py`: Step 2 (Recommended) option selection.
- `scripts/gui_automation/step3_click_submit_button.py`: Step 3 submit confirmation click.
- `scripts/gui_automation/step4_verify_execution.py`: Step 4 state verification and screenshot capture.
- `scripts/gui_automation/run_pipeline.py`: Master pipeline runner for sequential execution.
- `scripts/gui_automation/calibrate_coordinates.py`: Interactive calibration wizard.
- `scripts/gui_automation/README.md`: Bilingual technical documentation and usage guide.
